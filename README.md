Date: 8 August 2026 Title: Creating My Math Game

Today, I worked on creating a Math Game using Python and Pygame. The main idea of my game was to make learning mathematics more fun and interactive.

First, I learned how to use Pygame to create a game window and add different objects. Then, I created simple math equations, such as addition and subtraction. The answers appeared on the screen, and the player had to choose the correct answer.

I also added a scoring system. When the player chooses the correct answer, they get 2 points. When the player reaches 6 points, they receive 3 stars. I used Python commands and Pygame functions to make the game work.

While making the game, I faced some difficulties, especially with making the answers move correctly and detecting when the player clicked the correct answer. I solved these problems by checking my code and correcting the errors.

I felt happy and excited after seeing my game work. I learned that coding requires patience, creativity, and practice.

What I learned: I learned how Python and Pygame can be used to create an educational game.
